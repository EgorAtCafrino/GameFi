# AVAX-GOD Dashboard Assessment

A responsive dashboard prototype for an Avalanche-based gaming or digital-asset project.

## Assessment Goal

Build a clear, usable interface that demonstrates frontend development skills, problem-solving, code quality, and thoughtful handling of a blockchain-related product concept.

## Requirements

- Add a wallet-connect button with sample account information & payment flow UI.
- Display a list of sample game items, digital assets, or transactions.
- Implement one interactive feature, such as filtering, sorting, or viewing item details.
- Use mock data; a live blockchain integration is not required (empty Metamask wallet is enough).
- Include appropriate loading, empty, or error handling.
- Make the interface responsive across screen sizes.

## Time Limit

**3 hours**

Suggested breakdown:

- 30 minutes — Review requirements and plan & installing the development environment (Node.js & IDE & Metamask)
- 2 hours (120 minutes) — Implement the solution
- 30 minutes — Demonstrate the project and discuss decisions with simple documentation (report)
